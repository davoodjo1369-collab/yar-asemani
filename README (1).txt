یار آسمانی - نسخه نمایشی اولیه
================================

محتویات:
- index.html : صفحه اصلی و بخش‌های نمایشی برنامک
- logo.jpg : لوگوی مجموعه (در صورت وجود)

نکات:
1) این نسخه فقط پیش‌نمایش رابط کاربری است.
2) فرم ثبت‌نام عمداً هیچ اطلاعاتی را ارسال یا ذخیره نمی‌کند.
3) برای استفاده واقعی، به هاست با HTTPS و بخش سرور امن نیاز است.
4) قبل از ثبت اطلاعات واقعی نوجوانان، دسترسی مدیران، رضایت و اطلاع والدین،
   سیاست نگهداری اطلاعات و امنیت باید طراحی و تأیید شود.
5) فایل SDK رسمی ایتا از آدرس مستندات بارگذاری می‌شود:
   https://developer.eitaa.com/eitaa-web-app.js

برای تست اولیه، index.html را در مرورگر باز کنید.
برای اجرای داخل ایتا، ابتدا باید روی دامنه/هاست HTTPS منتشر و آدرس مقصد
در پنل ایتایار ثبت شود.


اتصال برنامه‌های هفتگی به Supabase
----------------------------------
- صفحه برنامه‌ها اطلاعات فعال را از جدول public.weekly_programs می‌خواند.
- کلید استفاده‌شده Publishable است و برای کد سمت مرورگر طراحی شده است.
- سیاست SELECT برای نقش anon باید فعال باشد و فقط ردیف‌های is_active=true را نمایش دهد.
- مدیر همچنان برنامه‌ها را از Supabase Table Editor ثبت/ویرایش می‌کند؛ فرم مدیریتی داخل اپ ساخته نشده است.
- فرم ثبت‌نام و حضور و امتیازها همچنان نمایشی هستند و اطلاعاتی ذخیره نمی‌کنند.
- پیش از استفاده واقعی، سیاست‌های RLS و تنظیمات امنیتی باید توسط مسئول فنی بررسی شوند.
